# StarFest Latinoamérica — GitHub Pages ready

Esta es una adaptación estática del sitio Lovable, conservando su arquitectura de navegación, contenido y formularios de demostración.

## Publicación
Sube **todo el contenido de esta carpeta** a la raíz del repositorio y configura GitHub Pages como `main` + `/(root)`.

## Formularios
Los formularios son funcionales a nivel de prototipo: validan y muestran confirmación, pero no envían datos a un backend. Eso se conectará en el hosting final.
